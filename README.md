# ConnecThing: 명지대학교 교내 분실물·기자재 통합 관리 플랫폼

#### **2026 SW Contest 출품작**

**ConnecThing**은 명지대학교 교내에서 발생하는 **분실물 관리**와 **기자재·시설 신고**를 하나의 플랫폼에서 제공하는 서비스입니다.

학생들은 분실물 및 습득물을 쉽게 등록·조회할 수 있으며, 기자재 고장 및 시설 개선 사항을 간편하게 신고하고 처리 현황을 확인할 수 있습니다.

저희의 목표는 **교내 생활의 불편을 줄이고 학교 구성원과 행정부서 간의 소통을 더욱 효율적으로 만드는 것**입니다.

## Installation

### 1. 패키지 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

## Commit Message

| 헤더 | 내용 |
| --- | --- |
| Feat | 새로운 기능 추가 |
| Refactor | 코드 리팩토링 |
| Fix | 버그 수정 |
| Style | 코드 스타일 수정 (기능 변경 없음) |
| Test | 테스트 코드 추가 및 수정 |
| Chore | 빌드 및 환경설정 |
| Docs | 문서 및 주석 수정 |

<br>

## Branch Convention

```text
main: 운영 브랜치
develop: 개발 브랜치
feat/{기능명}: 기능 개발
fix/{기능명}: 버그 수정
refactor/{기능명}: 리팩토링
docs/{문서명}: 문서 수정
```
